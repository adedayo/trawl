What you get

Built for clarity, provenance, and continuous drift detection

One Go engine powers both the standalone desktop application and the headless Docker server.

Discovery & Reachability

Deliberate external inventory

Combines certificate transparency, DNS, ASN and passive discovery with opt-in service reachability checks via embedded Vantage. Every connection is attributable to a named check against an authorised target.

Deterministic Priority

CISA KEV + EPSS ranking

Priority is a pure function of active exploitation (CISA KEV), exploitation likelihood (EPSS), and severity. Feed snapshots are content-addressed and staleness is disclosed everywhere a ranking appears.

Findings History

Append-only timeline & diffs

Every finding carries a stable key and an immutable event log: first seen, changed, priority moved, resolved, or reopened. Changes caused by a scanner or feed update are labelled separately from changes in your estate.

Offline Narratives

Plain-English explanations

Every finding explains what was found, why it matters, how it could be abused, what good looks like, and how a re-scan confirms the fix. Human-authored, deterministic, and works fully offline.

Software Inventory

Candidates kept apart from confirmed flaws

Observed banners and headers build a curated per-asset software inventory matched against NVD 2.0. Unconfirmed version matches stay clearly separated from demonstrated vulnerabilities.

Email, DNS & Secrets

Spoofing controls & git history

Validates SPF, DKIM, DMARC, MTA-STS, TLS-RPT, BIMI, CAA and dangling CNAMEs through Vantage, and scans full public git history for leaked credentials via embedded Checkmate with redaction at ingestion.

Engineering guardrails

"We did not look" must never render as "it is fine"

Assessment coverage is four-state throughout the engine, database, API and dashboard. A check that failed or never ran lowers coverage and never contributes the reassurance of a passing control.

ok · Assessed

The check ran, reached a conclusion, and the control is configured.

not_found · Not published

The check ran and concluded that the record or control is genuinely absent.

not_checked · Not checked

Never attempted (excluded by profile or egress policy). Not evidence either way.

check_failed · Could not tell

Attempted but inconclusive (resolver timeout, refused endpoint). An assessment gap, not a pass.

Get started

Run locally as a desktop app, or self-host for your team

Both distributions run the exact same Go engine and SQLite schema. No external database service required.

macOS Desktop

Homebrew Cask

Universal macOS build. Stores state locally in ~/.trawl/.

brew install --cask adedayo/tap/trawl
Linux & Windows Desktop

Native Packages

Signed checksums and Sigstore bundles for Debian, Fedora, AppImage, and Windows.

sudo apt install ./trawl_*_amd64.deb
sudo dnf install ./trawl-*.x86_64.rpm
Continuous Team Mode

Self-Hosted Docker Compose

Guided setup starts trawl-server, the dashboard, and scheduled workers.

git clone https://github.com/adedayo/trawl.git
cd trawl && ./setup.sh

Verifiable supply chain: Every release publishes SHA256SUMS, keyless Sigstore cosign signatures (.sig / .pem) logged in Rekor, and an SBOM.
